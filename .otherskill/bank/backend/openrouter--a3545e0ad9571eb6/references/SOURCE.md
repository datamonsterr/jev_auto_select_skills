`scripts/` copied from [openrouterteam/skills](https://github.com/openrouterteam/skills) → `skills/openrouter-models/scripts` (MIT/see upstream LICENSE).

To refresh:

```bash
git clone --depth 1 https://github.com/openrouterteam/skills.git /tmp/or-skills
cp /tmp/or-skills/skills/openrouter-models/scripts/* skills/openrouter/scripts/
```

Install without vendoring: `npx skills add https://github.com/openrouterteam/skills --skill openrouter-models`
